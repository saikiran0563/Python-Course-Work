# Assignment 1 — Movie Information Program

## Overview

A console-based Python program that collects movie information from the user and demonstrates different Python data types, collections, and string-formatting techniques.

## Concepts Practiced

- Integer and floating-point input
- Strings
- Lists created from comma-separated input
- Sets for lead actors
- Dictionaries for structured director details
- `input()` and type conversion
- `str.split()`
- `print()` with the `sep` argument
- Percentage formatting with `%`
- f-strings
- `.format()`

## What the Program Does

The program accepts details such as:

- Movie ID and title
- IMDb rating
- Genres
- Duration and release year
- Box-office collection
- Popularity score
- Lead actors
- Director name, contact, and country

It then prints a formatted movie information summary using multiple Python formatting approaches.

## Run

```bash
python Assignments/assignment-1.py
```

## Learning Outcome

This assignment reinforces Python input handling, data representation with built-in collections, and multiple approaches to formatting output.
