# Assignment 2 — Chat Data Analysis

## Overview

A menu-driven Python application that reads chat messages, stores them by user, and provides multiple analysis operations.

## Concepts Practiced

- Lists and dictionaries
- Functions
- Loops and conditionals
- String splitting and normalization
- Lambda expressions
- `collections.Counter`
- `max()` and `sorted()`
- Case-insensitive text matching
- Duplicate detection with sets
- Menu-driven CLI design

## Features

The program can:

1. Count total messages
2. Identify unique users
3. Count total words
4. Calculate average words per message
5. Find the longest message
6. Identify the most active user
7. Count messages for a selected user
8. Find a user's most frequent word
9. Retrieve a user's first used word
10. Check whether a user is present
11. Find repeated words
12. Identify the user with the longest average message
13. Count user mentions
14. Remove duplicate messages
15. Sort messages alphabetically
16. Extract questions
17. Calculate a reply ratio between users
18. Check for messages entered with empty content

## Input Format

Enter the number of messages first. Each message should follow the format:

```
username: message text
```

## Run

```bash
python Assignments/assignment-2.py
```

## Learning Outcome

This assignment combines Python data structures and functions into a small text-analysis application and provides practice with decomposing a larger problem into reusable operations.
