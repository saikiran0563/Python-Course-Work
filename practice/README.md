## How to Practise

Run one file at a time from the repository root:

    python "practice/3.bmi.py"
    python "practice/6.strongpass.py"

For each exercise:

- Work out the inputs and expected outputs before running the program.
- Try the smallest and largest sensible values.
- Consider invalid, negative, or missing input where relevant.
- Break long conditions into readable variables or helper functions.
- Re-solve the exercise later without opening the original code.

## Personal Improvement Goal

After solving an exercise, try a second version that places the core logic in a function and returns a result rather than only printing it. Pure functions are easier to test automatically.
