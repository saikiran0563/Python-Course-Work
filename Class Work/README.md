## How to Use These Examples

1. Open one file at a time.
2. Read the code and predict the output.
3. Run it from the repository root, for example:

       python "Class Work/1.Operators in Python.py"

4. Change sample values and explain the new output.
5. Write a similar example without copying the original.

Some scripts are interactive or demonstrate concepts by printing results; they are learning examples, not a packaged application.

## Review Tips

- Check boundary cases in conditions and loops.
- Prefer clear variable names and functions that return values when reusing logic.
- Do not place real passwords, PINs, or personal information in examples. Credential examples should contain dummy values only.
