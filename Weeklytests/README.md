# Weekly Tests — Assessment Practice

This folder preserves assessment exercises and helper functions used during Python practice. Use them to check understanding after studying the concepts in [Class Work](../Class%20Work/README.md) and [Practice](../practice/README.md).

## Files

| File | Purpose |
|---|---|
| [test-3.py](test-3.py) | Conditional logic, discounts, billing, loops, and PIN-style control-flow exercises |
| [test-5.py](test-5.py) | Lambda expressions, filtering, prime numbers, recursion, strings, generators, and nested data |
| [string_utils.py](string_utils.py) | Helper functions for palindrome checking and capitalization |

## Recommended Practice Method

1. Read a question and write down the expected behaviour before running code.
2. Attempt a solution in a scratch file first.
3. Test normal values, boundary values, empty values, and invalid input.
4. Compare with the class exercise and record what you would improve.
5. Revisit any question you could not solve independently.

## Important Notes

- Some answers in the assessment files are commented out, and files retain their classroom format.
- The filenames test-3.py and test-5.py use hyphens and contain interactive course exercises; they are not automatically discoverable as a normal pytest test suite.
- string_utils.py contains reusable helpers, but additional automated tests should be added before treating them as production-quality utilities.
- Avoid storing real PINs, passwords, or personal data in assessment scripts.
